Immich Wallpaper Rotator

Configure where photos come from and how the rotation behaves. This page only talks to your Immich server and to itself on localhost.

Immich server

Which permissions should this key have?

In Immich, go to Account Settings → API Keys → New API Key, give it a name like wallpaper-rotator, and grant only these read/download scopes (uncheck everything else — especially anything with write/delete/admin):

  • asset.read — see photo metadata
  • asset.download — download the actual image bytes
  • album.read — list albums to filter by
  • person.read — list people (face groups) to filter by

If your Immich version doesn't offer granular scopes, an all-permissions key also works — just keep it out of anything else and be ready to revoke it.
